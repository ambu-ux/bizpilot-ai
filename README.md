# BizPilot AI

Build a complete enterprise SaaS application called "BizPilot AI – Powered by Ambusise Amanyange".



Branding & Theme:

- Theme: Modern Dark Mode with Light Green accents (#2E7D32 primary dark green, #4CAF50 light green accents, #121212 dark background, #1E1E1E dark cards, #FFFFFF text).

- Company: Ambusise Amanyange Charcoal (Pty) Ltd (Reg: 2026/312659/07, MD: Siphosethu Hlanganise, Qonce).

- Footer: "Powered by Ambusise Amanyange | AI-generated content should always be reviewed before official business use."



Architecture (Frontend + Backend):

- Frontend: Single-page React app with Tailwind CSS, Lucide icons, responsive sidebar.

- Backend: Lovable Cloud/Supabase Edge Functions integration with open AI LLM API calls so ALL responses (emails, meeting notes, proposals, marketing, chat) are dynamically generated by AI based on real user inputs, not static template strings.



Main Sidebar Navigation:

1. Dashboard (KPI cards, quick actions, task summary)

2. AI Assistant (Live streaming chat with custom prompt chips)

3. Smart Email Generator (Dynamic AI draft based on purpose, recipient, and tone selection)

4. Meeting Assistant (AI extracts summary, key decisions, action items, deadlines from raw notes)

5. Task Planner (Interactive Kanban board with AI task prioritization)

6. Quotation Generator (Branded builder, 15% VAT, line items, print view)

7. Invoice Generator (Auto-numbering, 30-day terms, 10% late fee notice, PDF preview)

8. Funding Proposal Generator (AI investor proposal builder with live Funding Readiness Score)

9. Marketing Studio (AI-generated social copy and ad campaigns for Ambusise products)

10. Analytics (Interactive charts for productivity and AI usage)

11. Settings (Company profile configuration)



Requirements:

- Connect all generator modules directly to the backend AI API endpoint for real,

 dynamic text generation.
